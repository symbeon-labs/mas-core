# 🧠 Glossary of Sovereignty: Symbeon MAS Terms
**Institutional Nomenclature & Conceptual Standards**

## 🏛️ Foundational Primitives
- **HAAS (Hierarchical Autonomous Agent Swarm)**: The architectural pattern of organizing specialized AI agents into tiers of perception, logic, and execution.
- **Trinity Consensus**: The core quorum logic requiring a 2/3 agreement across Physical, Juridical, and Ethical domains to prevent data manipulation.
- **Sovereign DNA**: The set of rules, logic progenies, and toolsets that define an agent's specialized intelligence.

## 🔐 Cryptographic Concepts
- **ZK-Membrane (Selective Disclosure)**: The privacy layer that uses Zero-Knowledge Proofs to prove compliance without exposing the underlying sensitive data.
- **Algebraic Sovereignty**: The concept of truth based on mathematical proofs and consensus rather than trust in a single centralized entity.

## ⛓️ Infrastructure Layer
- **Chainlink CRE (Custom Runtime Environment)**: The programmatic backbone used to orchestrate off-chain compute and cross-chain workflows.
- **CCIP (Cross-Chain Interoperability Protocol)**: The standard for moving verified states and assets across different blockchain ecosystems.
